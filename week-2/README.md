# Week 2 – SQL Sales Data Analysis

## About the Assignment
This assignment is part of my Skillnexius internship. The objective is to analyze a sales dataset using SQL queries and extract useful business insights.

## Objectives
- Identify the top 10 customers based on total spending.
- Calculate the Average Order Value (AOV).
- Understand customer purchasing patterns using sales data.

## Tools Used
- MySQL
- MySQL Workbench
- SQL Sales Dataset (200 rows)

## SQL Concepts Practiced
- SELECT
- SUM()
- AVG()
- GROUP BY
- ORDER BY
- LIMIT
- Subqueries
- Column aliases

## Learning Outcome
Through this assignment, I learned how to group sales records, calculate customer spending, determine the average order value, and use subqueries to analyze sales data.

This assignment helped me improve my SQL query-writing and data analysis skills.
